流放之路 1 · 舆图天赋树完全指南（中文版）

本指南配套交互式中文舆图天赋树（index.html）：树上的每一个节点、每一条词缀都已中文化，并内置 12 套可一键预览的预设加点方案。

一、先弄清楚你在看什么

1.1 舆图天赋树是什么

舆图天赋树（Atlas Passive Tree，社区简称「天赋树 / 舆图天赋」）是流放之路终局（Endgame）的核心成长系统。它不强化你的角色，而是强化你的地图：

  • 让地图里出现哪种赛季机制（裂隙 / 驱灵 / 摧灭 / 军团……）
  • 让这些机制掉得更多、更难、奖励更好
  • 改变地图本身的规则（怪物群规模、物品稀有度、地图掉落、古灵祭坛、贤主见证……）

它是流放之路每个赛季「刷什么、怎么刷、赚什么」的总开关。同一套装备、同一个角色，舆图天赋点法不同，收益可以差出好几倍。

1.2 这棵树为什么从中间开始、往外扩

当前版本的舆图天赋树是中心辐射式结构：

  • 中心是舆图起点（不可分配，所有路径的根）
  • 从起点向外伸出若干条主干，每条主干通向一个机制区域
  • 每个机制区域有一个奥义石（Mastery）标记，只作区域标识，不可分配
  • 区域与区域之间通过跳跃点（Gateway）相连：古灵跳跃点、隐秘跳跃点、凡间跳跃点

因此加点有一条铁律：你只能沿着已经连通的路径往外点。点到远处的机制，路径上的每一个小点都要付点数——这也是为什么「点得远不如点得准」。

二、150 点从哪来

舆图天赋点不是靠升级拿的，而是靠完成终局目标逐步解锁。近年版本的点数来源可以归为四类（具体数值每个版本会调整，以游戏内「舆图天赋」面板右上角的 已获得 / 可获得 为准）：

  1. 地图完成度：在舆图上完成地图（含不同阶级、不同区域）会给予点数，这是最大头。
  2. 塑界之域 / 区域目标：完成一个塑造之域内的地图目标会推进该区域进度并给点。
  3. 首领见证与影响：贤主见证地图首领、焚界者 / 灭世者的影响进度、塑界者与裂界者（Uber Elder）相关的终局目标都会给点。
  4. 终局任务线：跟随奇拉克 / 指挥官基拉克的终局任务推进，会解锁一部分点数。

实用建议：每个赛季前两周，优先把「地图完成度 + 区域目标」这条线推满，因为它给的点数最多、最稳定；首领见证类目标可以边刷边补。点数没满之前，不建议把点分散到三四个机制区域——路径成本会让你每个机制都点半套。

三、先懂这 6 个「全树通用」概念

这 6 个概念几乎出现在每个机制区域里，看懂它们，整棵树就懂了一半。

3.1 超凡几率（Surpassing Chance）

树里大量出现「你的地图有 +X% 超凡几率 包含……」。——它不是一个独立概率，而是叠加在基础出现率之上、用于突破上限的那部分几率。通俗理解：普通「几率提高」是在原有池子里加权，超凡几率是额外再摇一次「保底出现」。所以带「超凡」的节点通常比同数值的普通几率节点更值钱，尤其是你想稳定刷某个机制时。

3.2 线团（Threads）

线团是取代圣甲虫的机制道具，在地图装置上使用，用来指定这张图出现哪种赛季机制。共 10 种：深渊、猎魔、背叛者、枯萎、裂隙、先祖秘藏、穿越、军团、驱灵仪式、摧灭。

树里与线团相关的节点分三类，配合使用效果最好：

  • 右旋之线 / 左旋之线：让你地图中的线团偏向某 5 种类型（+200% 几率）
  • 褴褛 / 无丝之线：让你地图中的线团不再出现某 5 种类型
  • 线团掉落几率：提高线团本身的掉落
关键理解：「右旋 + 褴褛」是一组「正反过滤」。先用正向把想要的机制权重拉高，再用反向把不要的机制踢出池子，你就能把线团稳定压到 1-2 种机制上。这是当前版本定向刷图的核心技巧。

3.3 塑造之域（Shaped Region）与星盘（Astrolabe）

舆图被划分为若干个塑造之域，每个域对应一种线团类型。域内的地图会免费获得该类型的线团；完成域内目标会额外给域内其他地图加线团。星盘（Astrolabe）则是把某个塑造之域「钉」在指定地图上的道具。

树里的「塑造山脉 / 塑造山谷 / 塑造天空 / 塑造世界」等节点，本质是在强化区域完成度与地图掉落这条线，属于「开图期」最划算的投入。

3.4 舆图异象（Atlas Anomalies）

舆图异象是在地图完成时随机「显现」的特殊事件（相当于地图里额外多一个可交互的奖励点）。关键天赋幻影异象把它从「完成地图时显现」改成「完成塑造之域时显现」，并且可以从任意象限显现——这意味着你可以用区域完成来「定向触发」异象，而不是纯看脸。

3.5 圣花 / 圣兽（Sacred Flora / Fauna）与荒野鬼火

庄园机制改为地图内直接生成圣花后，圣花成了命能的主要来源：

  • 圣花几率决定地图里有没有
  • 圣兽从圣花里生成，掉落命能；「圣兽复制」是爆发点
  • 荒野鬼火（Wildwood Wisps）由圣花散播，会强化被它附着的怪物（包括囚禁怪物）

所以「圣花 + 精华」是一条很自然的组合：鬼火强化囚禁怪物 → 精华怪更强更富。

3.6 怪物群规模 / 物品稀有度 / 物品数量

这三个是老朋友，但在当前版本里权重变了：

  • 怪物群规模（Pack Size）：影响怪物数量，间接影响一切掉落与经验，是「通用第一属性」
  • 物品稀有度（Item Rarity）：影响掉落品质（稀有 / 传奇），对通货影响较小
  • 物品数量（Item Quantity）：很多来源已被削弱或改名为「舆图掉落」，加点点数时优先看具体词缀而不是名字

四、机制详解（按区域）

每一节的结构：它是什么 → 树上该点哪些 → 关键节点（原文数值）→ 配套预设 → 避坑。 预设名对应网页左侧的卡片，点「预览」即可在树上看到完整加点路径。

4.1 裂隙（Breach）——最稳定的「量大管饱」

它是什么：地图中出现裂隙，涌出怪物；裂隙可升级为蜂巢（Hive）或不稳定裂隙（Unstable Breach），最终通向堡垒 / 裂隙首领。

树上该点哪些：

  • 出现与数量：裂隙几率、额外的不稳定裂隙几率、大军集结（额外 2 / 3 / 10 个不稳定裂隙）
  • 怪物质量：裂隙怪物群规模、裂隙魔法怪物几率、裂隙稀有怪物几率
  • 产出：虫巢之血数量、孕育之礼数量、丰饶之巢（首领 50% 额外孕育之礼）
  • 玩法改造：分而治之（裂隙遭遇始终为蜂巢 / 不稳定裂隙）、利爪撕裂（不稳定裂隙延迟 8 秒坍塌 + 稳定时生成 2 个额外稀有怪）

关键节点原文：

  • 分而治之（多选一）：你地图中的裂隙遭遇始终为蜂巢 / 不稳定裂隙
  • 大军集结：包含不稳定裂隙的地图有 10% 几率额外包含两个、5% 几率三个、1% 几率十个不稳定裂隙
  • 多线战场：不稳定裂隙每已开启一个，速度加快 10%；其怪物每已开启一个裂隙，难度与奖励提高
  • 固若金汤：裂隙蜂巢通往堡垒的几率提高 60%；裂隙首领 25% 几率被复制
  • 围城鏖战：艾莉丝在不通往堡垒的蜂巢内创造的技能数量提高 100%；蜂巢额外拥有 3 波蜂巢怪物

配套预设：裂隙专精 · 不稳定裂隙 + 线团定向（103 点，多选：分而治之=不稳定裂隙、右旋之线=裂隙、褴褛=驱灵仪式）

避坑：

  • 「分而治之」只能二选一。选蜂巢就走「围城鏖战 / 燃起的火焰」；选不稳定裂隙就走「大军集结 / 利爪撕裂」。不要混着点。
  • 裂隙是「怪多但杂」的机制，装备不够时先点生存向的群规模，而不是把首领节点全点了。

4.2 驱灵仪式（Ritual）——祭品商店的长线收益

它是什么：地图中生成驱灵祭坛，击杀怪物积累祭品（Tribute），在祭坛商店兑换奖励。祭品可以重掷、延迟。

树上该点哪些：

  • 祭坛数量：神秘奉献（带祭坛的地图始终有四个祭坛）
  • 祭品收益：血契（祭品 +30%）、严苛祭品（复生怪物祭品惩罚 -10%；祭坛击杀传奇怪物 +100% 祭品）
  • 商店操作：灵活信条（额外重掷 2 次 + 1 次免费重掷）、盲目效忠（装备类祭品未鉴定且可带物品阶级）
  • 特殊奖励：葬礼仪式（特殊奖励几率 +50% + 额外稀有物化尸体）、牺牲的理由（最终祭坛 25% 掉落盛血容器）

配套预设：驱灵专精 · 四祭坛 + 祭品滚雪球（101 点，多选：右旋之线=驱灵仪式、褴褛=摧灭）

避坑：

  • 祭品是「越滚越大」的机制：先保证四个祭坛与祭品获取，再考虑重掷。
  • 「延迟祭品」是长线玩法：今天延迟、明天取，适合每天固定刷几张图的人。

4.3 摧灭（Ultimatum）——轮次与奖励池

它是什么：在祭坛接受试炼，一轮轮加难度加奖励；失败则失去奖励。

树上该点哪些：

  • 轮次收益：不动如山（视同额外完成一轮）、烈火试炼（每回合经验 +10%、物品稀有度 +4%）
  • 奖励池：试炼大师的恩赐（多选：通货 / 传奇 / 命运卡）、彰示神威（词缀起始阶级 +1、奖励 25% 复制）
  • 难度控制：受控混乱（多选：保护祭坛 / 击败波次 / 站石阵 / 只存活）、远古机巧（随机回合被替换为超级灵魂回合）
  • 首领：勇攀高塔（首领掉落 10 个随机催化剂、最终轮首领几率 +30%）

关键节点原文：

  • 不动如山：摧灭遭遇每轮使范围缩小 3%；摧灭遭遇会视同你额外完成了一轮来给予奖励
  • 彰示神威：摧灭词缀在可能的情况下起始阶级提高一级；摧灭奖励有 25% 的几率被复制

配套预设：摧灭专精 · 不动如山 + 奖励复制（104 点，多选：受控混乱=保护祭坛、试炼大师的恩赐=通货、右旋之线=摧灭、褴褛=裂隙）

避坑：

  • 「受控混乱」一定要选你能稳定完成的类型。选错类型 = 每把都失败。
  • 摧灭是少数「难度换收益」的机制，装备不够时先只点奖励池，不点难度。

4.4 古灵祭坛（Eldritch Altars）——焚界者 / 灭世者

它是什么：地图被焚界者或灭世者影响时，会出现古灵祭坛，交互后获得「正面效果 + 负面效果」的增益组合，并掉落古灵通货与影响底子。

树上该点哪些：

  • 焚界者路线：宇宙之怒（祭坛 50% 几率多一个正面效果，但负面效果 +100%）
  • 灭世者路线：古神凝视（祭坛额外一个负面效果，正面效果 +50%）
  • 影响与掉落：焚界者影响群规模、灭世者影响群规模、焚界者物品几率、灭世者物品几率
  • 首领：总督御令、黎明之光、火焰洗礼

关键节点原文：

  • 宇宙之怒：受焚界者影响的古灵祭坛 50% 几率拥有一个额外正面效果；拥有额外正面效果的古灵祭坛，其负面效果提高 100%
  • 古神凝视：受灭世者影响的古灵祭坛额外拥有一个负面效果；其正面效果提高 50%

配套预设：古灵祭坛 · 焚界者 + 稀有怪（121 点；想刷灭世者就把焚界者那半换成灭世者 + 古神凝视）

避坑：

  • 两个基石是两种玩法，不要都点：焚界者是「高风险高上限」，灭世者是「稳定正面」。
  • 古灵祭坛的收益很大程度取决于你能不能吃下负面效果；脆皮 BD 优先灭世者。

4.5 惊悸迷雾（Delirium）——拟像与星团珠宝

它是什么：地图中出现迷雾，越往深处强度越高、奖励越好；迷雾尽头有拟像（Simulacrum）与星团珠宝（Cluster Jewel）。

树上该点哪些：

  • 出现：惊悸迷雾几率、这就是你所求（迷雾之镜额外几率）
  • 奖励进度：奖励进度、额外奖励几率、毕生所求（首领掉落拟像裂片与传奇星团）
  • 星团：星团珠宝几率、迷雾宝珠奖励几率
  • 强度：坠入疯狂（镜子远方的迷雾强化速度 +50%）

配套预设：惊悸迷雾 + 深渊 · 群怪密度流（117 点）

避坑：

  • 迷雾是「越深越赚、越深越痛」的机制。先确定你是刷拟像裂片还是星团珠宝，两者的加点权重完全不同。
  • 迷雾强度与地图词缀叠加，装备没成型前不要点「强化速度」类节点。

4.6 圣花 / 命能（Sacred Flora）——庄园的替代路线

它是什么：庄园不再有独立区域，改为地图内生成圣花；圣花生成圣兽，圣兽掉命能；圣花散播荒野鬼火强化怪物。

树上该点哪些：

  • 出现：圣花几率（+15% 超凡）、翠绿之地、自然恩泽
  • 产量：圣兽复制几率、圣花鬼火数量、肥沃土壤
  • 质变：古灵庄园之心、双倍季节、林木栽培、硕果累累

配套预设：圣花 + 精华 · 鬼火养囚禁怪（103 点）

避坑：

  • 圣花几率决定「有没有」，圣兽复制决定「有多少」，两者要平衡，不要只堆一边。
  • 鬼火会强化囚禁怪物——如果你同时点精华，这条线会额外赚。

4.7 贤主见证（Maven）——首领连战

它是什么：贤主见证你地图的首领战；击杀被见证的首领可以推进贤主进度、掉落贤主凿刀与专属物品。

树上该点哪些：

  • 见证与额外首领：贤主见证额外首领几率
  • 召唤：毁灭游戏（关键天赋）——贤主见证地图首领时施放「加注」，召唤 1-3 个额外舆图首领；剩余怪物越少召唤越多；最终首领的词缀也会作用于这些首领
  • 产出：贤主钉几率（贤主凿刀）、恐怖之巅、死而埋葬

配套预设：贤主首领 · 见证连战（113 点）

避坑：

  • 「毁灭游戏」的收益与地图剩余怪物数直接挂钩：清完图再打首领，收益最高。
  • 贤主凿刀只有镶嵌仪庆虚空石（Ceremonial Voidstone）时才会掉。

4.8 佣兵（Mercenaries）——恶名与传奇装备

它是什么：地图中会出现佣兵（Mercenary），可以招募 / 击杀；恶名佣兵（Infamous）装备更好、掉落更多。

树上该点哪些：

  • 出现：佣兵几率、恶名佣兵几率
  • 装备：佣兵传奇物品几率、至少 3 件装备为传奇
  • 团队：佣兵光环效果、佣兵额外辅助几率、佣兵冷却回复速度
  • 职业定向：佣兵职业为野蛮人 / 决斗者 / 圣堂 / 女巫 / 暗影 / 游侠 / 贵族（多选）

配套预设：佣兵 + 盗贼流放者 · 恶名与野生（103 点）

避坑：

  • 佣兵是「装备驱动」的机制：恶名佣兵的装备池更好，但强度也更高。
  • 职业定向节点只有在你要刷特定职业的佣兵装备时才值得点。

4.9 保险箱 + 命运卡（Strongbox / Divination Card）——低强度稳定流

它是什么：保险箱提供额外掉落；命运卡是固定兑换的收藏品。

树上该点哪些：

  • 保险箱：保险箱几率、保险箱重开几率、保险箱额外群几率、保险箱至少稀有
  • 命运卡：命运卡几率、命运卡几率与魔法怪物、命运卡被最终首领偷取（双刃剑）

配套预设：保险箱 + 命运卡 · 低强度稳定流（108 点，附加盗贼流放者）

避坑：

  • 「命运卡被最终首领偷走」会让首领更强，但卡片可复制——只在你能稳杀首领时点。
  • 保险箱是开荒期最友好的机制，不依赖角色强度。

4.10 先祖秘藏（Expedition）——炸药与文物

它是什么：地图中放置炸药，炸开遗迹，获得文物与日志；商人（罗格 / 格温妮 / 图真 / 丹尼格）提供服务。

树上该点哪些：

  • 炸药：先祖秘藏炸药范围、炸药放置范围、爆破专家、受控引爆
  • 遗迹与符文：遗迹数量、符文怪物、神器数量
  • 极限玩法：极限考古（关键天赋：炸药数量为 1，范围 +200%，怪物缺失 10% 生命，放置范围 +100%）
  • 带队：罗格 / 格温妮 / 图真 / 丹尼格带队几率

配套预设：先祖秘藏 + 卡古兰 · 炸药与矿脉（102 点）

避坑：

  • 「极限考古」只给一发炸药，但范围巨大——熟悉布局后再用，否则会漏掉大量遗迹。
  • 带队节点按你需要的商人服务选，不要四个都点。

4.11 军团（Legion）——将军、中士与碎片

它是什么：地图中冻结着军团怪物，点击后解冻，限时击杀；将军（General）与中士（Sergeant）提供额外奖励。

树上该点哪些：

  • 将军：军团将军几率、双将、将军掉落遮蔽水晶几率
  • 中士与宝箱：中士奖励几率、军团宝箱碎片几率、军团怪物碎片几率
  • 玩法改造：永战无休（关键天赋：军团遭遇没有计时器，破除停滞会引发裂变，裂变后开始）
  • 类型倾向：卡鲁 / 永恒帝国 / 瓦尔 / 圣堂 / 马拉克斯军队几率

配套预设：军团专精 · 永战无休 + 碎片（94 点，多选：左旋之线=军团、无丝之线=深渊）

避坑：

  • 「永战无休」取消了计时器，但节奏变成「引爆裂变」，需要适应。
  • 类型倾向决定你拿哪种碎片，按你要换的奖励选。

4.12 枯萎（Blight）——塔防与枯萎地图

它是什么：保护菌潮泵，建造 / 升级防御塔，抵御一波波怪物；奖励枯萎宝箱与枯萎地图。

树上该点哪些：

  • 宝箱：枯萎宝箱额外奖励几率、枯萎宝箱包含枯萎地图几率、幸运宝箱
  • 塔：防御塔消耗、强化防御塔、圣堂奇才（塔可回收）
  • 怪物：枯萎怪物数量、枯萎怪物稀有度、菌丝虫群

避坑：

  • 枯萎是「策略 > 强度」的机制：塔的布局比角色输出更重要。
  • 「卡西娅之傲」是双刃剑：枯萎怪物减伤 75%，但塔的伤害 +300%——适合塔防流，不适合清怪流。

4.13 深渊（Abyss）——深渊珠宝与深层

它是什么：地图中出现深渊裂缝，沿裂缝推进，最终打开深渊宝藏 / 深渊之坑 / 深层（Abyssal Depths）。

树上该点哪些：

  • 出现与额外：深渊几率、深渊额外巨坑几率、深渊怪物数量
  • 珠宝：深渊珠宝几率、深渊珠宝腐化、深渊珠宝隐匿词缀
  • 深层：绝望深渊几率、觉醒黑渊
  • 首领：乌姆布拉 / 库尔加 / 阿玛纳姆 / 乌拉曼（四种深渊首领的倾向节点）

避坑：

  • 深渊珠宝是这条线的主要产出；「深渊珠宝腐化 + 隐匿」是追高价值珠宝的关键。
  • 深层（Abyssal Depths）是额外战斗，装备不够时可以只点珠宝线。

4.14 背叛者（Betrayal）——辛迪加与安全屋

它是什么：地图中出现不朽辛迪加成员，击杀 / 审讯 / 处决会影响成员阶级与安全屋进度；安全屋提供专属奖励。

树上该点哪些：

  • 成员：辛迪加成员额外隐匿物品、目标物品稀有度、辛迪加援军几率
  • 阶级：额外提升阶级几率、不掉阶级几率、交易几率
  • 首领：揭开秘密、蛇之首、苛刻交易、暗藏侧翼

避坑：

  • 背叛者是「运营型」机制：阶级与安全屋的规划比刷图速度更重要。
  • 多选一节点（如「揭开秘密」）按你要的奖励类型选，不要乱点。

  1. 网页左侧点「预览」→ 树上会用绿色高亮显示这套方案的完整路径，底部出现方案条（含「主玩法 / 附加 / 过路」点数拆分）。

预设不是「点满 150」

这些预设的核心只有 94–133 点，剩下的 17–56 点是故意留白的：

  • 想补生存：去地图 / 稀有怪物区拿群规模与防御向基石
  • 想接第二个玩法：优先选离主玩法区域近的机制，路径成本最低（树上有跳跃点直连的优先）
  • 不要为了「点满」去点起点附近那圈通用大点——那正是上一版预设最大的问题，收益被摊薄、每个玩法都不精

七、加点方法论（专家级）

7.1 三步定方向

  1. 先确定「产出」：你要刷什么？通货、传奇、星团珠宝、裂隙石、命能、文物……不同产出对应不同机制。
  2. 再确定「强度」：你的 BD 能吃什么难度？古灵祭坛的负面、迷雾的深层、摧灭的轮次，都是「强度换收益」。
  3. 最后算「路径成本」：从起点到目标区域的路径上，有多少点是「必须路过的垃圾点」？如果一个机制区域要 40 点路过费，它就不适合作为副机制。

7.2 一条主玩法 + 一条副玩法

150 点足够「一条主玩法点满（约 90–120 点）+ 一条副玩法补核心（约 30–50 点）」，但不够两条都点满。判断顺序：

  1. 主玩法区域里的大点是否都值得点？不值得就删掉，别为了「完整」硬点。
  2. 副玩法优先选与主玩法同图 / 同怪物池 / 同奖励类型的：例如圣花 × 精华（鬼火强化囚禁怪）、迷雾 × 深渊（都吃怪物密度）、贤主 × 征服者/守卫（首领连战）。
  3. 剩余 10–20 点再补通用（地图供给、群规模、生存）。

7.3 什么时候该「跳点」

跳跃点（Gateway）让你可以从一个区域跳到另一个区域。当你需要两个相距很远的机制时，先看它们之间有没有跳跃点直连——有的话，路径成本会大幅下降。

7.4 路径成本速查

  • 中心区（起点周围 1-2 圈）：路径成本最低，但不要为了凑点数而点——通用小点收益低，是上一版预设被诟病的原因
  • 中环：大部分机制的显著天赋集中在这里，是主力区域
  • 外环：关键天赋与高阶节点，路径成本最高，只点你真正需要的

八、常见问题（FAQ）

Q：为什么我点不了某个节点？ A：舆图天赋必须连通。你只能点与「起点或已点节点」相邻的节点。工具会自动帮你补最短路径。

Q：多选一节点选错了怎么办？ A：在工具里点该节点会弹出选择菜单，可以随时改选；游戏内需要洗点。

Q：150 点够点满两个机制吗？ A：通常不够。两个机制各点核心骨架大约需要 90-110 点，加上路径成本很容易超过 150。建议「主机制 + 通用」而不是「两个机制各半套」。

Q：为什么有的节点在游戏里找不到？ A：版本差异。舆图天赋树每个大版本都会改，本页数据以页面为准；以游戏内为准。

Q：这些中文名是官方译名吗？ A：优先采用官方中文（poedb.tw/cn 收录的客户端文本），新机制与官方尚未收录的节点为人工校译，术语尽量与官方保持一致（如「摧灭」「驱灵仪式」「先祖秘藏」「线团」）。
